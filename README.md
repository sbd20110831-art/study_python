자 여러분 연산자 중에선 산술 연산자와 비교 연산자, 논리 연산자, 멤버 연산자가 있는데 산술 연산자는 +(더하기), -(빼기), *(곱하기), /(나누기), //(값), %(나머지), **(제곱)등을 하는 연산자입니다. 예: 1 + 1 = 2, 3 - 2 = 1, 5 * 2 = 10, 5 / 2 = 2.5, 8 // 3 = 2, 9 % 4 = 1, 4 ** 3 = 64
비교 연산자는 >(크다), <(작다), >=(크거나 작다),<=(작거나 크다), ==(같다), !=(같지 않다) 등의 연산자들이 있습니다. 예: 3 > 5 = False, 3 < 5 = True, 2 >= 2 = True, 4 <= 6 = True, 7 == 6 = False, 2 != 4 = True
논리 연산자는 and(둘다 참이여야지만 True), or(하나라도 참이면 True), not(반전됨) 등이 있습니다. 예: 10 > 3 and 3 == 1, 7 <= 6 or 2 != 3, 
멤버 연산자는 in(포함), not in(미포함) 등이 있습니다. 그 다음 멤버round가 뭔지 아세요? 대충 반올림할 때 쓰이는 함수입니다. (인덱스와 비슷해용)이게 -와 +가 있는데 먼저 +는 소수점을 남겨라 라는 의미인데 예를 들어 round(1.234, 2) 이렇게 있으면 2니깐 즉 "소수점 2번째 자리까지 남겨라."라는 겁니다. 즉 1.23이 나옵니다. round(1.5000, 4)하면 어떻게 나올까요? 1.5가 나옵니다! 즉 0은 생략합니다.
